# 🌙 MyAstroBoard Org

**Open-source tools that get your astrophotography nights ready - from planning to post-processing.**

---

### ✨ Our projects

#### 🔭 [MyAstroBoard](https://github.com/myastroboard/myastroboard)
The self-hosted dashboard for planning your session: weather, observing conditions, ephemerides, tonight's targets and your personal collection, all in one place.

- 🔭 **Plan My Night** - session timeline, exportable to CSV/PDF
- 📒 **Astrodex** - your personal catalog of captured objects
- 🌤️ **Observing conditions** - real-time forecasts (Open-Meteo)
- 🌕 **Ephemerides** - moon, sun, eclipses, aurora, ISS passes
- 🗂️ **Multiple catalogues** - Messier, Herschel 400, OpenNGC, LBN, LDN…
- 🛠️ **Equipment profiles** - telescopes, cameras, mounts, filters + FOV calculator
- 🌍 **Multilingual** - English, French, Spanish, German…

```bash
docker pull myastroboard/myastroboard:latest
```

#### ✨ [MyAstroShine](https://github.com/myastroboard/myastroshine) - *Alpha*
The image processing companion: a self-hosted editor for enhancement, depth effects and stacking - no account, no cloud upload.

- 🖌️ **Workflow editor** - framing, background corrections, curves, colour, detail
- ⚡ **Auto Astro** - one-click adaptive enhancement + built-in presets
- ⭐ **Star handling** - shrink in place, or remove and screen-blend back
- 🌌 **Depth Shift** - parallax effect with a pickable focal point
- 🧩 **Stacking** - calibration, registration, sigma-clipped combination, drizzle
- 🤖 **Optional ML engines** - StarNet2 / DeepSNR for star removal and denoise
- 🔗 **AstroDex integration** - signed webhook, and fully standalone

```bash
docker pull myastroboard/myastroshine:latest
```
